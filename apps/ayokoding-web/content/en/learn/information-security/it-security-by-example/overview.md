**Want to learn IT security through practical, annotated examples?** This by-example guide
teaches essential security skills through hands-on code, configurations, and attack/defense
scenarios covering **network security, system hardening, cryptography, and incident response**.

## What Is IT Security By-Example Learning?

IT security by-example learning is a **scenario-first approach** where you learn through
annotated, runnable code and real-world configurations rather than pure theory. Each example shows:

- **What it does** — step-by-step annotations documenting system state, network traffic, or
  configuration effects
- **Why it works** — rationale behind security controls and attack mechanics
- **When to apply it** — practical guidance on deploying each technique
- **Trade-offs** — security vs. usability vs. performance considerations in context

This approach is **ideal for IT professionals and developers** who want to build security intuition
by working through concrete, realistic scenarios.

## Learning Path

The by-example guide covers examples organized into three progressive levels, from foundational
security concepts to advanced security engineering.

## Coverage Philosophy

This guide achieves broad coverage of IT security through annotated scenarios mixing shell
scripts, configuration files, tool output, and decision frameworks.

### What Is Covered

- **Network security** — firewall rules, packet analysis, TLS configuration, VPN setup
- **System hardening** — OS hardening, patch management, least-privilege configuration
- **Cryptography in practice** — symmetric/asymmetric encryption, hashing, PKI, certificate management
- **Vulnerability assessment** — scanning, CVE analysis, CVSS 4.0 risk scoring, remediation prioritization
- **Cloud security basics** — cloud IAM misconfigurations, CSPM concepts, shared responsibility model
- **Incident response** — detection, containment, eradication, recovery, and post-incident review
- **Identity and access management** — authentication, authorization, MFA, privilege escalation prevention
- **Security monitoring** — log analysis, SIEM queries, anomaly detection baselines

### What Is Not Covered

- Formal offensive exploitation techniques (see Red Team by Example)
- Strategic security governance and risk management (see CISO by Example)
- Active threat hunting and detection engineering (see Blue Team by Example)

## Prerequisites

- Familiarity with Linux/Unix command line
- Basic understanding of networking (TCP/IP, DNS, HTTP)
- Comfort reading configuration files and shell scripts

## Structure of Each Example

Every example follows a consistent five-part format:

1. **Brief Explanation** — what the example demonstrates and why it matters (2-3 sentences)
2. **Scenario Context** — the system environment or threat scenario being addressed
3. **Annotated Code or Configuration** — runnable scripts, configs, or tool output with inline
   comments documenting state and decisions
4. **Key Takeaway** — the core security insight to retain (1-2 sentences)
5. **Why It Matters** — real-world impact and production relevance (50-100 words)
