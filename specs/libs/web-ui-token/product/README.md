## Overview

`web-ui-token` is the shared design-token package for the open-sharia-enterprise monorepo. It
exports structural tokens (border radius, base neutral palette, semantic colors, spacing,
typography) shared across every app; brand tokens (primary, accent, per-app OKLCH palettes such
as OrganicLever's warm hues) are overridden per app.

See [overview.md](./overview.md) for the full product overview.
