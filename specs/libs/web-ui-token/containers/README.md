# Containers — web-ui-token

C4 Level 2 containers for `web-ui-token`.

`web-ui-token` ships as a single container: a TypeScript/CSS constants package
(`@open-sharia-enterprise/web-ui-token`) consumed at build time by every frontend app in the
workspace. It has no separate deployable runtime of its own.

See [container.md](./container.md) for the C4 container diagram placeholder.
