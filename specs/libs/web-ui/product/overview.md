# web-ui — Product Overview

`web-ui` is the shared React component library for the open-sharia-enterprise monorepo. It
provides accessible, themeable UI building blocks in two tiers:

- **Base components** — Button, Alert, Dialog, Input, Card, Label, Textarea, Badge — built on
  shadcn/ui patterns, Radix UI primitives, and Tailwind CSS.
- **OrganicLever components** — Icon, Toggle, ProgressRing, Sheet, AppHeader, StatCard, InfoTip,
  HuePicker, TabBar, SideNav — specific to the OrganicLever warm OKLCH design system.

See [README.md](./README.md) for C4 L1 product framing.
