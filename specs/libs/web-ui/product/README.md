## Overview

`web-ui` is the shared React component library for the open-sharia-enterprise monorepo, built on
shadcn/ui patterns with Radix UI primitives and Tailwind CSS. It provides the accessible,
themeable building blocks (Button, Alert, Dialog, Input, Card, Label, and the OrganicLever warm
design-system components) consumed by every TypeScript frontend in the workspace.

See [overview.md](./overview.md) for the full product overview.
