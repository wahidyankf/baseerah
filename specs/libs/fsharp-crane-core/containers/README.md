# Containers — fsharp-crane-core

C4 Level 2 containers for `fsharp-crane-core`.

`fsharp-crane-core` ships as a single container: an F# class library
(`fsharp-crane-core.fsproj`, root namespace `CraneCore`) compiled into the `crane-cli` binary at
build time. It has no separate deployable runtime of its own — it is a library project, not an
executable.

See [container.md](./container.md) for the C4 container diagram placeholder.
